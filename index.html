I'm Mir Eashan Zaman, a Computer Science & Engineering student at American International University-Bangladesh (AIUB), focused on distributed backend APIs, enterprise web systems, cross-platform mobile apps, and interactive canvas engines.

I design systems from database schema to client interface using NestJS, TypeORM, PostgreSQL, Next.js, and Capacitor. My work applies patterns such as Saga Orchestration, Strategy, Observer, and token-bucket rate limiting alongside real-time WebSocket workflows.

Outside enterprise software, I build browser arcade games with custom physics and particle loops on the HTML5 Canvas API.
